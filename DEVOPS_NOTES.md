# DevOps Notes

## CI/CD Basics
- Continuous Integration (CI): Merge code changes into a shared repo with automated tests.
- Continuous Delivery (CD): Automatically deploy tested code to staging/production.
- Tools: Jenkins, GitHub Actions, GitLab CI, CircleCI.

## Agile Workflow
- Work is divided into sprints (1–2 weeks).
- Focus on incremental delivery with frequent feedback.
- Key concepts: Scrum, Kanban, user stories, standups, retrospectives.

## GitOps & Infrastructure as Code (IaC)
- GitOps: Git as the single source of truth for deployments.
- IaC: Manage infrastructure using code rather than manual setup.
- Tools: Terraform, Ansible, CloudFormation.

## Observability Concepts
- Logs: Capture system and application events.
- Metrics: CPU, memory, latency, etc.
- Alerts: Triggered when metrics cross thresholds or errors occur.
- Tools: Prometheus, Grafana, ELK Stack (Elasticsearch, Logstash, Kibana).
